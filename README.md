VELMARA: Streets of Gold — an open-world crime game in 2D top-down. Riko Vale returns to the city of Velmara (3600×2600): 12 chained missions across 3 acts, a branching choice in mission 7 (Marisol vs Broker), a 0–5 star wanted system with patrol cops, foot cops, roadblocks (3★) and a helicopter with a spotlight (4★), combat, a living economy (taxi fares that double at night, 24 gold coins, 3 street races, garage upgrades, a gun shop, Pay N' Spray, a safehouse), live traffic and pedestrians, GPS autopilot that follows the road graph, 3 WebAudio radio stations with adaptive music, HUD + 220×160 minimap + compass, 8 districts, a day/night cycle, and localStorage saves.

## Run it

```sh
node main.ts
```

This writes the whole game to `/output/index.html` — open it in any modern browser. No build step, no dependencies, no network.

## Controls

WASD move/drive · E enter/exit car, interact · F punch · G shoot · Space handbrake · Tab GPS autopilot · 1/2/3 radio · M mission · P pause.
